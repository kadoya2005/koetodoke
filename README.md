# こえとどけ（試作）

遠くに住む家族に、自分の声を「決めた時刻」に届けるアプリの試作です。

**ブラウザで開く：https://kadoya2005.github.io/koetodoke/**（マイクを使うので https:// で開いてください）

## 画面の流れ

- **送る人**：だれに → 声を録音（6秒まで）→ いつ（1回だけ／毎日／曜日）→ 確認して送る
- **受け取る人**：届いた声の一覧・次に鳴る時刻。時刻になると全画面で声が流れる（「試しに鳴らす」ですぐ確認できる）

## この試作でできないこと

- サーバーにはつながっていません。同じスマホの中で、右上の「送る人／受け取る人」を切り替えて試します
- 画面を開いている間しか鳴りません（本番は Android アプリにして、閉じていても鳴るようにする予定）
- 録音した声はこのスマホのブラウザの中だけに保存されます
